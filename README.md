# BookingSlot

A web-based booking system that allows users to book available time slots for services such as rooms, meetings, and consultations.

## Features

- Book available time slots
- Manage booking information
- User-friendly booking interface
- Backend integration using Flask
- Database management using SQL

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQL
- JSON
- Git
